# Security Policy

Glori installs software and can run privileged commands, so security reports are taken seriously.

## Reporting a vulnerability

Do not open a public issue. Report privately through the repository's private security advisory feature (GitHub: Security > Report a vulnerability).

Include the affected version, steps to reproduce and the impact. You will receive an acknowledgement and a fix timeline.

## Scope

- Path traversal or unsafe extraction of archives
- Privilege escalation or unintended use of root
- Unverified downloads executing code
- Registry tampering that causes unintended deletion
